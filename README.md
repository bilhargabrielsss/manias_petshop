# Manias Petshop

Site de um petshop fictício, feito apenas com HTML, como Fase 1 do projeto da disciplina Fundamentos de Sistemas Web.

## Funcionalidades

- Página inicial com algumas informações do que se trata 
- Página de produtos com todos os produtos e categorias disponivéis
- Página de serviços com todos os tipos de serviços prestados pelo petshop
- Menu de navegação no cabeçalho e no rodapé
